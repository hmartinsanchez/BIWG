1. Zer desberdintasuna dago var eta let artean?

2. Eta let eta const artean?

let aldagai balioa edozein momentuan aldatu daiteke. const konstateak direlako ezin dira berriro esleitu.

3. Zer diferentzia dago == eta === artean?

=== datu-mota berdina izatea eskatzen du eta == motak bihurtzen ditu alderatu aurretik

4. Zer desberdintasuna dago while eta do-while artean?
